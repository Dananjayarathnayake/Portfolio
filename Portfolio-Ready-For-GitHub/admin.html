How Live Updates Work

Method 1: Instant Local / Browser Sync
Whenever you click Save All Changes, your site updates in real-time in your browser and on your local server. If your portfolio tab is open, it updates live!

Method 2: Direct GitHub API Publish
Add your GitHub Token and Repo name above, then click Publish to GitHub Live Site. It automatically commits the new portfolio_data.json directly to GitHub, updating your live site for all visitors worldwide!

Method 3: One-Click JSON Export
Click the Export JSON button in the top bar to download your updated portfolio_data.json file, and drag it into your GitHub repo anytime.
